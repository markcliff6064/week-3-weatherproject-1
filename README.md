# Weather Dashboard

## About the Project
A simple weather dashboard built using HTML, CSS, and JavaScript. It allows users to search for a city and view its current weather and a five-day forecast.

![How the project worked when i searched a city Los angeles](https://github.com/markcliff6064/week-3-weatherproject-1/blob/6761167162990aec9d0fe46253d851e4e0486bdc/1.png)

![How the project worked when i searched a city New york](https://github.com/markcliff6064/week-3-weatherproject-1/blob/6761167162990aec9d0fe46253d851e4e0486bdc/2.png)

## Features
- Search for weather by city name.
- Display temperature, weather description, humidity, wind speed, and feels-like temperature.
- Show a five-day weather forecast.
- Display loading messages and handle errors.
- Save the last five searched cities using localStorage.
- Responsive design for desktop and mobile.

## Technologies Used

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Get an API key from [OpenWeatherMap](https://openweathermap.org/).
4. Open `script.js` and replace `your_api_key_here` with your API key.
5. Open `index.html` in your browser or use Live Server.
6. Enter a city name and click **Search**.

## Project Files
- `index.html` — Page structure.
- `styles.css` — Page styling.
- `script.js` — Weather API and JavaScript functionality.
